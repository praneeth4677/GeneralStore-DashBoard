# 📊 Power BI Sales Analytics Dashboard

## 📌 Project Overview

This project is an interactive **Sales Analytics Dashboard** developed using **Microsoft Power BI** to analyze sales performance and generate meaningful business insights.

The dashboard helps understand key performance indicators such as **Sales, Profit, Quantity, Discounts, Shipping Cost, Returns, and Market/Regional performance** through interactive visualizations.

---

## 🎯 Objectives

* Analyze overall sales and profit performance
* Identify top-performing products
* Understand sales trends over time
* Compare performance across different markets/regions
* Analyze returned orders
* Monitor important business KPIs
* Present data through an interactive and user-friendly dashboard

---

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query** – Data cleaning and transformation
* **DAX** – Calculated measures and KPIs
* **Data Visualization**
* **Exploratory Data Analysis (EDA)**

---

## 📂 Dataset

The project uses multiple tables:

### Orders

Contains transactional sales information such as:

* Sales
* Profit
* Quantity
* Discount
* Shipping Cost
* Product information
* Customer information
* Market/Region
* Order Date

### People

Contains information related to people/sales representatives.

### Returns

Contains information about returned orders.

These tables were connected using relationships in the Power BI data model.

---

## 📊 Key KPIs

The dashboard includes important metrics such as:

* **Total Sales**
* **Total Profit**
* **Total Quantity**
* **Profit Margin %**
* **Return Rate %**
* **Average Shipping Cost**
* **Top 10 Products by Sales**

---

## 📈 Dashboard Features

### Sales Performance

Provides an overview of total sales, profit, and quantity.

### Profit Analysis

Helps identify profitable and less-profitable products and segments.

### Sales Trends

Displays sales performance over time to identify trends and changes.

### Product Analysis

Highlights the **Top 10 Products by Sales**.

### Market/Regional Analysis

Allows comparison of business performance across different markets or regions.

### Returns Analysis

Provides insights into returned orders and helps understand the return rate.

### Interactive Filters

Users can filter and explore the dashboard based on available dimensions such as:

* Date
* Market/Region
* Product
* Customer
* Category

* Total Profit

* Return Rate
* Average Shipping Cost

These measures were then used throughout the dashboard visualizations.
